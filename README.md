## 🔬 Technical Deep Dives

### Complex Hadamard Gate Fix
Previous implementations only mixed real components. Our v2 handles full complex state:
```typescript
const r_i = this.real[i], m_i = this.imag[i];
const r_j = this.real[j], m_j = this.imag[j];
this.real[i] = (r_i + r_j) * invSqrt2;
this.imag[i] = (m_i + m_j) * invSqrt2;
this.real[j] = (r_i - r_j) * invSqrt2;
this.imag[j] = (m_i - m_j) * invSqrt2;
```

### Full Amplitude Mapping (16,384 → 9,216)
No longer dropping 7,168 amplitudes. We now interpolate the full Hilbert space into the 96×96 canvas with:
- **Phase → HSL hue** (0–360°)
- **Magnitude → Brightness** (0–100%)

Deprecated `u1(lambda)` replaced with `p(theta)`:
